# Work Done

This folder tracks what got done in each milestone or PR. Every meaningful chunk of work should have a short matching write-up so it is easy to see what changed and reproduce it later.

Each write-up should explain what changed, why the work matters, how to run or test it, any important setup notes or assumptions, and what comes next.

The goal is practical project history, not a formal research paper. These notes should stay clear, specific, and useful.
